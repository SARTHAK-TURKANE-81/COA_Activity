Pipeline Execution Simulator

Five-stage RISC pipeline (IF, ID, EX, MEM, WB) with data hazards, forwarding, stalls and branch handling. Step through one clock cycle at a time.

1. Program

Supported instructions 
add  rd, rs, rt      sub  rd, rs, rt
and  rd, rs, rt      or   rd, rs, rt
slt  rd, rs, rt      addi rd, rs, imm
lw   rt, off(rs)     sw   rt, off(rs)
beq  rs, rt, label   bne  rs, rt, label
j    label           nop   halt
li   rd, imm         move  rd, rs
Registers: r0..r31 (r0 is always 0)
Labels:    name:   Comments: # or ;
Memory: 256 words, byte addresses must be
multiples of 4 (word 2 = address 8).

2. Pipeline parameters

Changing a parameter restarts the simulation from cycle 0.

3. Controls

Keyboard: Right arrow = step, Left arrow = back, Space = play or pause.
